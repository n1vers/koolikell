# SchoolBell

## Автоматические школьные звонки для Windows

SchoolBell помогает школе настроить расписание звонков, выбрать звуки и запускать звонки автоматически. Программа работает локально на компьютере Windows и подходит для ежедневного использования в школе.

Установщик находится в официальном [GitHub Release v1.0.0](https://github.com/n1vers/koolikell/releases/tag/v1.0.0).

## Что умеет программа

- создавать несколько профилей расписания для разных дней и режимов;
- назначать профиль на каждый день недели;
- задавать исключения для отдельных дат;
- автоматически воспроизводить звонки по расписанию;
- запускать предварительный звонок за заданное количество минут;
- выбирать отдельный звук для обычного звонка и предзвона;
- загружать собственные звуки и управлять библиотекой аудиофайлов;
- запускать музыку вручную через PlayNow;
- собирать плейлист, менять порядок треков и выбирать режим повтора;
- показывать журнал звонков и событий;
- работать в системном трее;
- запускаться вместе с Windows, в том числе в свёрнутом виде;
- проверять точность времени через NTP-сервер.

## Преимущества

- **Просто настроить.** Основные параметры собраны в понятных разделах.
- **Гибкое расписание.** Можно использовать разные профили и менять их для отдельных дат.
- **Свои звуки.** Добавляйте школьные звонки, музыку и предзвоны.
- **Автоматическая работа.** После настройки программа сама воспроизводит звонки по расписанию.
- **Локальная работа.** Расписания и звуки хранятся на компьютере школы.
- **Бесплатный open source.** Исходный код открыт и доступен для проверки и развития.

## Установка

1. Скачайте установщик по ссылке в разделе [Скачать](#скачать).
2. Запустите файл SchoolBell.Setup.1.0.0.exe.
3. Следуйте инструкциям установщика.
4. Запустите SchoolBell через меню «Пуск» или ярлык на рабочем столе.

Программа рассчитана на **Windows 10 и Windows 11**.

## Быстрый старт

1. Откройте раздел **Звуки** и добавьте аудиофайлы.
2. Создайте профиль в разделе **Расписания** и добавьте время звонков.
3. Назначьте профиль на дни недели или конкретные даты.
4. В разделе **Настройки** выберите устройство вывода, громкость и время предзвона.
5. Оставьте программу запущенной. При необходимости включите автозапуск Windows.

## Обновление

Для новой версии скачайте свежий установщик из раздела [Releases](https://github.com/n1vers/koolikell/releases) и установите его поверх текущей версии. Ваши локальные настройки и данные должны сохраниться.

## Для разработчиков

### Требования

- Windows 10/11;
- Node.js 20 или новее;
- npm.

### Запуск из исходного кода

```powershell
npm install
npm --prefix client install
npm --prefix server install
npm run electron
```

### Сборка Windows-установщика

```powershell
npm run dist:win
```

Готовые файлы появятся в папке release:

- SchoolBell Setup 1.0.0.exe — установщик Windows;
- win-unpacked/SchoolBell.exe — portable-сборка для локальной проверки.
